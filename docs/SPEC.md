## 5. 💡 補充：實作建議

簡報沒有規定以下細節，這裡是建議做法。

### 5.1 建置指令

專案已用 create-next-app 建好（TypeScript、App Router、ESLint、pnpm），直接：

```bash
pnpm install
pnpm dev
```

### 5.2 目錄結構（App Router）

```
app/
├── layout.tsx            # 共用 <html>/<body>
├── page.tsx              # /  首頁（Header、Banner、點此開始）
└── accounting/
    └── page.tsx          # /accounting（'use client'，持有 records state）
components/
├── Form.tsx              # 類型、金額、說明、新增紀錄
└── List.tsx              # 紀錄列表與刪除
types/
└── record.ts
```

### 5.3 型別與狀態

```ts
// types/record.ts
export type RecordType = 'income' | 'expense'

export interface AccountRecord {
  id: string // crypto.randomUUID()
  amount: number // 收入為正、支出為負
  description: string
}
```

- `records` 狀態放在 `accounting/page.tsx`，用 `useState<AccountRecord[]>`。
- `Form` 接收 `onAdd(record)`，`List` 接收 `records` 與 `onDelete(id)`：狀態往上提，資料往下傳。
- 小計用 `records.reduce((sum, r) => sum + r.amount, 0)` 直接算，不必另存 state。
- 頁面切換用 `next/link` 的 `<Link>` 或 `useRouter().push()`。
- 有用到 `useState` 或事件處理的檔案，開頭要加 `'use client'`。
- 想重新整理後資料還在，可以用 `useEffect` 同步到 `localStorage`（選做；第二週會換成 Firebase）。

### 5.4 輸入驗證（建議）

- 金額需大於 0；空白或非數字時不新增。
- 說明不可為空。
- 新增成功後清空輸入框。

## 6. 部署到 Vercel

📌 簡報原文（Slide 8）：

```
 Local Machine           Git Service            Vercel
 ┌─────────┐   sync    ┌──────────┐  deploy  ┌─────────┐
 │ Project │ ◀───────▶ │  GitHub  │ ───────▶ │ Hosting │
 └─────────┘           └──────────┘          └─────────┘
```

本機專案與 GitHub 雙向同步，Vercel 從 GitHub 拉程式碼部署。

💡 補充步驟：

1. 在 GitHub 建立 repository，`git push` 專案。
2. 到 vercel.com 用 GitHub 登入 → **Add New Project** → 匯入該 repository。
3. Framework 會自動偵測為 Next.js，直接 **Deploy**。
4. 之後每次 push 到 `main`，Vercel 會自動重新部署。
5. 部署前先在本機跑一次 `npm run build`，確認 TypeScript 與 lint 沒有錯誤。
